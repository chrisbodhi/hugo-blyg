Each directive line becomes a placeholder paragraph (blank lines around it, indentation kept, so it's a block of its own even inside a list item), the body is rendered, and each placeholder is swapped for the snapshot, baked by this same partial in the source's own page context -- the same rendering that produced the source's content_html, which scripts/blyg_validate.py checks byte for byte while the source still sits at the baked version. A quoted thread's snapshot bakes its own snapshots the same way, so nesting is nested blockquotes. A partial transclusion's placeholder takes its attached blockquote's lines too, and bakes as the selection's plain text, once the source's text content is checked to contain it.
